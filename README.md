ЭПриложение разрабатывается для удовлетворения потребностей в области анализа данных и визуализации расчетов.

**Основные задачи** это машинное обучение и классификация данных скважин, по данным геофизики

**Второстепенные задачи** - работа с данными, сортировка, анализ, обработка;
                            построение структуры по данным сейсмики или по данным ЗСБ.
