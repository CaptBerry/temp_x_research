Приложение разрабатывается для удовлетворения потребностей в области анализа данных и визуализации расчетов.

**Основные задачи** это машинное обучение и классификация данных скважин, по данным геофизики

**Второстепенные задачи** - работа с данными, сортировка, анализ, обработка;
                            построение структуры по данным сейсмики или по данным ЗСБ.

Stack:
- Python 3.12
- PyQt6
- PyVista
- NumPy
## Проект визуализации

Приложение может открывать готовый проект из JSON-файла. Пример находится в `projects/example_project.json`: он содержит тестовую поверхность и набор точек, загружаемый из `data/example_points.csv`.

Для запуска примера:

```bash
python main.py
```

После загрузки проекта камера автоматически фокусируется на объектах сцены. Положение камеры можно сохранить через объект проекта: `MainWindow.save_project(path)` обновляет параметры камеры и записывает проект в JSON-файл, чтобы позже продолжить работу.
